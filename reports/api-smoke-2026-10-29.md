# 本机 HTTP API 冒烟验证（2026-10-29）

环境：Windows、Python `llm-lab`、MovieLens-1M 预处理目录、Ollama 默认模型 `qwen2.5:1.5b`。服务只绑定 `127.0.0.1:8765`。以下是一次请求的观察值，不是延迟分位数或批量成功率。

## 启动与请求

```powershell
python scripts/serve_api.py --processed-dir data/processed/ml1m --port 8765
```

另开 PowerShell 窗口：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/health
$body = @{ query = "想看科幻，不要恐怖"; user_id = 6040; top_k = 3; mode = "baseline" } | ConvertTo-Json
Invoke-RestMethod -Uri http://127.0.0.1:8765/recommend -Method Post -ContentType "application/json; charset=utf-8" -Body ([Text.Encoding]::UTF8.GetBytes($body))
# 将 mode 改为 "llm"，在已启动 Ollama 时重试。
```

## 实测摘要

| 请求 | HTTP | 状态 | 回退 | 推荐 ID | 工具调用 | Agent 延迟 |
| --- | ---: | --- | --- | --- | --- | ---: |
| `/health` | 200 | ok | — | 目录 3,883 部 | — | — |
| `mode=baseline` | 200 | ok | false | 1270, 2571, 1580 | history → recall → rank | 1,079.9 ms |
| `mode=llm` | 200 | ok | false | 1527, 1356, 2699 | recall → rank | 3,087.6 ms |

LLM 请求用量：prompt 5,592 tokens，completion 109 tokens，总计 5,701 tokens。两次推荐 ID 不同；系统只保证候选与题材证据校验，不主张这条查询能够证明 LLM 提升了推荐质量。30 条冻结任务上的直接完成率与回退分布另见[对话评测](dialogue-ml1m-2026-10-29.md)及[默认 Qwen 兼容报告](ollama-default-compatibility-2026-10-29.md)。

自动验证：`pytest -q` 356 passed；`ruff check .`、`ruff format --check .`、`mypy recagent` 均通过。FastAPI TestClient 在当前受限沙箱里会卡住线程，因此接口测试在本机权限下执行。测试库报告一条 Starlette `httpx` 兼容层弃用提示，不影响请求结果。
