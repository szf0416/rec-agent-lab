## 一、W1 反向传播与自动微分

| 考点 | 一句话结论 | 证据 |
| --- | --- | --- |
| 反向传播怎么推 | 链式法则逐层回传，**每个梯度必须与对应参数形状一致** | 🔢 与 PyTorch 误差 **2.78e-17**（float64）|
| 矩阵求导转置 | `dW = Aᵀ @ dZ`，用形状反推：`(in,batch)@(batch,out)=(in,out)` ✓ | 🔢 形状全部对齐 |
| `backward()` 做什么 | 从 loss 反向遍历计算图，梯度写入**叶子张量**的 `.grad` | 中间张量需 `retain_grad()` |
| **`.grad` 是累加** | 同一个 batch 连续两次 backward，梯度**翻倍**（累加，非覆盖） | 🔢 W1 实验 4：`6.0 → 12.0` |
| ⟶ 推论 1 | 训练每步必须 `zero_grad()`，否则**等效学习率放大 N 倍** | |
| ⟶ 推论 2 | 梯度累积正是**利用**累加：4 个 micro-batch 累加后 step，模拟 4× batch | |
| **梯度累积要除** | `(loss / accum_steps).backward()`。不除累积的是**梯度和**而非平均 | 🔢 SGD 下与真大 batch 差异 **1.33e-07** |
| 计算图何时释放 | `backward()` 后自动释放；推理用 `torch.no_grad()` 省显存 | 忘记加会 OOM |
| `retain_grad()` | 非叶子节点默认不保留 `.grad`，需显式调用 | 或用 `torch.autograd.grad(loss, t)` |
| **ReLU 在 0 的导数** | 数学不可导，工程约定为 **0**（PyTorch 实测） | 🔢 `z=0.0 → grad=0.0`，`z=1e-30 → 1.0` |
| **数值梯度检验的边界** | 不可导点处中心差分得 `0.5`，解析次梯度 `0` → **差 0.5** | 🔢 含 0 点误差 **4.50e-03** vs 无 0 点 **5.21e-12**（差 9 个数量级）|
| 中心差分 vs 前向 | 中心差分 O(ε²)，前向 O(ε)。ε 取 1e-4~1e-5 | 🔢 数值梯度误差 1e-11~1e-13 |
| 梯度消失 | `σ'(x) ≤ 0.25`，10 层后 `0.25¹⁰ ≈ 9.5e-7` | 🔢 sigmoid 在 x=10 处导数 **4.54e-05** |
| 残差为何有用 | `∂(F(x)+x)/∂x = ∂F/∂x + 1`，那个 **+1** 是梯度直通路径 | |

## 二、W2 训练循环工程

| 考点 | 一句话结论 | 证据 |
| --- | --- | --- |
| **为什么用回调** | 开闭原则 / 可测试 / 可组合 / 关注点分离 | 加 `MLflowLogger` 时 `loop.py` **零改动** |
| **抽象合格标准** | 「加新功能时**是否被迫改核心**」：被迫改→抽象漏了；只加文件+一行→对了 | 🔢 `git diff` 可核对 |
| 回调注册顺序 | `ModelCheckpoint` 必须在 `EarlyStopping` **之前**，否则保存的是恢复后的权重、名实不符 | |
| **warmup 与 scheduler 顺序** | warmup 必须在 `scheduler.step()` **之后**，否则被覆盖 | 🔢 纯函数实测 `step 0..3`：`1e-5→3.4e-4→6.7e-4→1e-3` |
| ⟶ 关键性质 | **配错不会报错**，只是曲线不对 → 静默错误比崩溃危险 | |
| ⟶ 记录粒度陷阱 | `lr_history` 每 epoch 只记一次，而 warmup 是 **step 级** → 曲线里看不到 warmup 轨迹 | 想观察什么，就得记到什么粒度 |
| **EarlyStopping 三条** | ① 基于验证集 ② 提升后 wait 归零 ③ **必须恢复最优权重** | |
| 不恢复的后果 | 停止时停在最后一轮，**丢掉最好的模型**，且不报错 | |
| scheduler 分流 | epoch 级（StepLR/Cosine）每轮 step 一次；step 级（OneCycleLR）每次 optimizer.step 后 | 🔢 `last_epoch` 实测吻合 |
| **checkpoint 必须含** | model + optimizer + scheduler + **config 快照** + **git_commit** + torch 版本 | 只存 state_dict 一个月后无法复现 |
| 可复现的要点 | **先 `seed_everything` 再建模型**；DataLoader 的 `worker_init_fn` 也要设 | 🔢 同 seed 两次 loss 序列完全相同 |
| 配置同步守卫 | yaml 漏字段**不报错**（用默认值）→ 用测试断言字段集合相等 | 🔢 填充时当场抓到 `checkpoint_dir` 漏写 |

## 三、W3 过拟合与正则化

| 考点 | 一句话结论 | 证据 |
| --- | --- | --- |
| **过拟合 vs 欠拟合判据** | 看 **`train_loss`**：低而 gap 大→过拟合；**本身就高→欠拟合** | 🔢 `capacity_nomlp`: train_loss **0.4905**, gap **0.0773** |
| 两者对策相反 | 过拟合→加正则/降容量；**欠拟合→加容量/减正则** | 误判方向会越修越差 |
| **gap 作为核心度量** | `gap = valid_loss − train_loss`，平滑且直接度量泛化差距 | ndcg 在 520 用户下噪声大 |
| dropout 最有效 | 随机丢弃行为，破坏"记住用户-物品组合" | 🔢 gap **0.0117→0.0041**（压缩 65%），退步率 15.4%→**4.1%** |
| weight decay 效果有限 | 本模型过拟合来自 embedding 查表记忆，不是参数范数大 → wd 不对症 | 🔢 三种强度 gap 只降 0.0004~0.0020 |
| 组合正则不叠加 | wd 1e-2 + dropout 0.3 达到"接近强 dropout 的泛化 + 不打折的指标" | 🔢 gap **0.0058**, ndcg **0.1708**（并列最高）|
| **Adam vs AdamW** | Adam 的 wd 走 **L2 路径**（进梯度）；AdamW **解耦**（直接作用参数）| |
| Adam+L2 为何杀 embedding | 稀疏行无梯度但被衰减，且衰减经 Adam 归一化被**放大成完整一步** | 🔢 train_loss 卡在 **ln(2)=0.6931**（输出恒为 0）|
| 推荐系统必用 AdamW | Adam+L2 实质是**惩罚冷门物品**（越冷门越少激活→越快衰减到 0），与长尾目标冲突 | |
| **评测协议一致性** | 训练负样本**动态重采样** + 评测**固定** → 目标错位 | 🔢 train_loss 0.622→0.495 且 valid_ndcg 0.1445→**0.1312**（同步降）|
| ⟶ 这不是过拟合 | 是**评测信号失效**，无法用来比较正则化 | |
| ⟶ 修复 | 训练负样本也一次性固定 | 意外收益：训练**提速 12 倍**（32s→2.6s/轮）|

## 四、曲线形状 = 诊断工具

**画 loss 曲线不是交作业，是排查手段。**

| 曲线形状 | 诊断 | 处置 |
| --- | --- | --- |
| train 降 + valid **同步降** | ⚠️ 协议错配，信号失效 | 检查训练/评测候选集是否一致 |
| train_loss 恒为 **ln(2)** | ⚠️ 输出恒为 0（被压死） | 检查优化器与 weight_decay |
| 最优轮次**恒为 0** | ⚠️ 容量不足，观察不到过拟合 | 加容量（实验设计无效） |
| train 降 + valid **先升后降** | ✅ 健康曲线 | 可以开始对比正则化了 |
| lr 曲线看不到 warmup 上升段 | ⚠️ **记录粒度不足**（`lr_history` 是 epoch 级） | 想观察什么现象，就得记到对应粒度 |

## 六、答题结构模板

> **现象 → 诊断 → 规则**（这个顺序比结论本身有说服力）

**示例**（被问"怎么保证实验结果可靠"）：

> "我踩过一个坑：训练负样本每轮动态重采样、评测用固定集合，结果是
> train_loss 下降但 valid_ndcg 也下降。**这不是过拟合，而是训练目标与评测
> 目标错配，评测信号本身失效了。** 后来我定了几条规矩：实验前先做信号
> 有效性检查、用 gap 而非单一排序指标判断过拟合、以及**异常整齐的数字
> 先怀疑**——比如 train_loss = ln(2) 看着像收敛，实际是模型输出恒为 0。"

**三个原则**：
1. 先说结论，再给理由，最后给证据
2. **有数字就说数字**（"误差 2.78e-17" > "误差很小"）
3. 不知道就说不知道，然后给"我会怎么查"
