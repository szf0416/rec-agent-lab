> - 部署：int8 量化 + vLLM 推理服务 + FastAPI + Docker Compose，
>   P99 延迟从 **xx ms** 降至 **xx ms**，单卡 QPS 提升 **xx 倍**

### 为什么这么写

| 写法 | 面试官读到的信息 |
| --- | --- |
| "从零构建全链路" | 有系统能力，不是只会调库 |
| "手写 + 数值对齐" | 懂底层，能自证正确性 |
| 具体指标 + 提升幅度 | 有量化意识，结果可信 |
| "自研 + 框架对照" | 既懂原理又会用工具 |
| 部署 + 延迟/QPS | 有工程落地能力 |

**反例（不要这样写）**：

- ❌ "使用 LangChain 构建 RAG 推荐系统" —— 看不出你做了什么
- ❌ "熟悉深度学习、Transformer、大模型" —— 这是技能罗列，不是项目
- ❌ "显著提升了推荐效果" —— 没有数字等于没有结论

## 2. 30 分钟讲解稿框架

| 时长 | 内容 | 要点 |
| --- | --- | --- |
| 0–3 min | **问题与动机** | 为什么推荐系统需要 Agent？现有方案的三个不足 |
| 3–6 min | **系统架构** | 分层图 + 一次完整请求的数据流 |
| 6–12 min | **推荐引擎** | 多路召回设计、SASRec 为什么有效、DIN 解决什么问题 |
| 12–18 min | **LLM 微调** | 指令数据怎么造、QLoRA 怎么选参、怎么证明有效 |
| 18–24 min | **Agent 设计** | ReAct 循环、工具设计、记忆机制、容错与终止条件 |
| 24–27 min | **实验结果** | 消融表逐层分析（**这是最有说服力的部分**） |
| 27–30 min | **反思与改进** | 失败案例、局限、如果重做会怎么改 |

**心法**：讲解的重心放在**决策与权衡**，不是罗列技术名词。
每说一个技术选择，都跟一句"为什么不选另一个"。

## 3. 高频追问 Q&A（S7 填答案）

> 使用方式：**不要现在写答案**。每完成对应阶段，回来把这一节填上。
> 能写出来 = 真懂了；写不出来 = 那个阶段需要回头补。

### 关于推荐系统（S3 后填）

1. 为什么用时间切分而不是随机切分？随机切分会虚高多少？
2. 你的负采样怎么做的？负样本如果采错了会怎样？
3. NDCG 的公式是什么？为什么推荐系统爱用它而不是 AUC？
4. SASRec 相比 GRU4Rec 的优势在哪？自注意力的计算复杂度是多少？
5. DIN 的注意力机制和 Transformer 的注意力有什么区别？
6. 多路召回怎么做融合？RRF 和加权求和的取舍？
7. 冷启动问题你的方案怎么处理？
8. 推荐系统的指标有准确率之外的维度吗？覆盖率、多样性怎么衡量？
9. 你的模型有多少参数？训练一次多久？推理延迟多少？

### 关于深度学习与 Transformer（S1/S2 后填）

10. 手写一遍反向传播的关键步骤。
11. 为什么 Attention 要除以 √d_k？
12. Multi-Head 里每个头的维度是多少？为什么不是把所有头拼起来再算一次？
13. LayerNorm 和 BatchNorm 的区别？为什么 Transformer 用 LayerNorm？
14. 位置编码为什么必要？RoPE 相比绝对位置编码好在哪？

### 关于 LLM 微调（S4 后填）

15. LoRA 的原理是什么？为什么能减少可训练参数？
16. rank 和 alpha 怎么选？选大了会怎样？
17. QLoRA 的 4bit 量化损失在哪？为什么还能保持效果？
18. 你怎么构造指令数据？有没有数据泄漏？
19. 怎么证明微调有效，而不是 prompt 写得好？
20. 灾难性遗忘怎么检测？怎么缓解？
21. DPO 相比 RLHF 的优势？DPO 的损失函数是什么？

### 关于部署（S5 后填）

22. 量化后精度掉多少？怎么评估这个"掉"？
23. vLLM 的 PagedAttention 解决什么问题？
24. 连续批处理（continuous batching）为什么能提升吞吐？
25. 你的服务 P99 延迟多少？瓶颈在哪？

### 关于 Agent（S6 后填）

26. ReAct 和 Plan-and-Execute 的区别？各自适用场景？
27. Agent 死循环怎么防？你的终止条件是什么？
28. 工具数量多了怎么办？工具描述怎么写模型才调得对？
29. 多轮对话的记忆怎么存？无限增长怎么办？
30. 你怎么量化"Agent 好不好"？评测集怎么造？
31. 自研 ReAct 和 LangGraph 的区别？框架帮你做了什么？
32. Agent 的失败案例有哪些？怎么归因？

- 团队怎么衡量一个推荐策略上线后的收益？
